# Learning Analytics API

FastAPI backend for the diploma project: "Проектирование системы анализа результатов обучения в интерактивной образовательной среде по информационной безопасности".

## Что входит

- JWT-аутентификация (`register`, `login`, `me`)
- модели пользователей, курсов, модулей, уроков, заданий, тестов, вопросов и попыток
- CRUD для учебного контента
- учет завершения уроков
- запуск, прохождение и завершение тестов
- персональная аналитика, результаты по темам и рекомендации
- групповая, курсовая и модульная аналитика

## Структура

- `backend/main.py` - точка входа FastAPI
- `backend/models.py` - SQLAlchemy-модели
- `backend/schemas.py` - Pydantic-схемы
- `backend/api/` - роуты API
- `backend/core/` - настройки и безопасность
- `backend/db.py` - подключение к БД

## Запуск

1. Активировать виртуальное окружение:

```powershell
.\venv\Scripts\Activate.ps1
```

2. Установить зависимости:

```powershell
pip install -r requirements.txt
```

3. Запустить приложение:

```powershell
uvicorn backend.main:app --reload
```

4. Документация Swagger:

- `http://127.0.0.1:8000/docs`
- `http://127.0.0.1:8000/redoc`

## По умолчанию

- используется SQLite-база `app.db`
- таблицы создаются автоматически при старте
- в `User` хранится не открытый пароль, а его хеш

## Замечание

Для демонстрации регистрация позволяет передавать `role`. Для production-версии лучше ограничить создание ролей `teacher` и `admin` отдельным администраторским сценарием.
