# Learning Analytics Diploma Project

Проект состоит из FastAPI backend и Angular frontend для учебной платформы с курсами, модулями, уроками, заданиями, тестами и аналитикой прогресса.

## Актуальная версия

- Backend: `1.1.0`
- Frontend: регистрационная форма синхронизирована с backend `1.1.0`

## Что входит в проект

- JWT-аутентификация: `register`, `login`, `me`
- Управление курсами, модулями, уроками, заданиями и тестами
- Прохождение тестов и расчёт прогресса
- Персональная и агрегированная аналитика
- Angular-клиент с экранами входа, регистрации, профиля и дашборда

## Ключевые изменения в 1.1.0

- Самостоятельный выбор роли при регистрации отключён.
- Любой новый пользователь создаётся только с ролью `student`.
- Допустимые роли пользователя ограничены значениями `student`, `teacher`, `admin`.
- Прямой доступ к тестам, вопросам тестов и старту попытки теперь закрыт для неопубликованных курсов.
- На frontend поле `Course year` стало выпадающим списком со значениями от `1` до `6`.

## Политика ролей

- `student` создаётся через публичную регистрацию.
- `teacher` и `admin` должны назначаться отдельно: через административный сценарий, сидирование данных или прямое изменение БД.
- Передача поля `role` в `POST /api/auth/register/` больше не поддерживается.

## Структура

- `backend/` - FastAPI-приложение
- `frontend/` - Angular-приложение
- `data/` - JSON-данные для наполнения/ориентира
- `postman/` - Postman-коллекция
- `BackendUpdates.md` - backend-документация и changelog

## Запуск backend

1. Активировать виртуальное окружение:

```powershell
.\venv\Scripts\Activate.ps1
```

2. Установить зависимости:

```powershell
pip install -r requirements.txt
```

3. Запустить API:

```powershell
uvicorn backend.main:app --reload
```

4. Открыть документацию:

- `http://127.0.0.1:8000/docs`
- `http://127.0.0.1:8000/redoc`

## Запуск frontend

1. Перейти в каталог `frontend`:

```powershell
cd frontend
```

2. Установить зависимости:

```powershell
npm install
```

3. Запустить dev-сервер:

```powershell
npm start
```

## База данных

- По умолчанию используется `SQLite` база `app.db`.
- Таблицы создаются автоматически при старте backend через `Base.metadata.create_all(...)`.
- После обновления до `1.1.0` существующие записи пользователей должны содержать только роли из набора `student | teacher | admin`.

## Примечание

Если в проекте нужны новые преподаватели или администраторы, их следует создавать не через публичную регистрацию, а отдельным доверенным сценарием.
